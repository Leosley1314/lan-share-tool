# 局域网共享工具 (LAN Share Tool)

Windows 一键配置局域网共享，支持磁盘/文件夹/打印机共享，内置网络工具与系统维护。纯 PowerShell 脚本，无需安装，双击即可运行。

## 功能

- 图形界面（GUI），无需命令行
- 选择磁盘或自定义文件夹共享
- 一键共享所有非 C 盘磁盘（隐藏磁盘不共享，仅 NTFS）
- 取消所有共享（关闭 SMB1 + 停止 Server 服务）
- 无密码访客访问 / 指定用户名密码
- 网络发现开关 / 打印机共享开关
- 只读 / 读写权限
- 查看当前共享状态
- 配置完成后显示 Windows / 手机访问地址
- 自动启用 SMB1（注册表 + DISM）
- 自动配置防火墙（专用/公用网络均放行）
- 自动启动所需系统服务

### 网络工具

- 本机信息：IPv4 地址 / 默认网关 / MAC 地址（多适配器动态检测）
- 局域网 IP 扫描：并发 Ping 全段扫描 + ARP 解析
- 在线设备识别：根据 MAC 厂商前缀识别手机/路由器/电脑等设备类型
- 在线设备双击打开网络位置
- 互传能力检测：SMB 445 端口连通性逐台测试
- 代理 / VPN 检测
- 网络发现检测（服务状态 + 防火墙规则 + 当前配置文件）

### 系统维护

- 重启资源管理器
- 共享连接监控（会话连接 / 打开的文件，可断开/关闭）
- 修复防火墙（恢复文件和打印机共享规则 + 445/137-139 端口放行）
- 修复网络（重置 Winsock + IP 协议栈）
- 网络重置（重置协议栈 + 重启网络适配器）

## 兼容性

- Windows Vista / 7 / 8 / 8.1 / 10 / 11
- PowerShell 2.0+（全部使用 WMI / net / sc / netsh / 注册表，无现代 Cmdlet 依赖）
- 需要管理员权限

## 使用

1. 双击 `lan-share.ps1`（如遇安全提示，选择"仍然运行"）
2. 首次打开显示免责声明，点"接受"进入
3. 选择共享内容（磁盘 / 自定义文件夹），点"开始配置"
4. 按提示允许管理员权限，等待自动完成

也可以直接用命令行参数运行：

```
powershell -ExecutionPolicy Bypass -File lan-share.ps1 -SharePath "D:\" -NoPause
```

常用参数：`-SharePath` 共享路径、`-ShareAll` 共享所有非 C 盘、`-ClearAll` 取消所有共享、`-ReadOnly` 只读、`-NoGuest` 关闭无密码访客、`-NoDiscovery` 关闭网络发现、`-NoPrinter` 关闭打印机共享、`-FixFirewall` / `-FixNetwork` / `-NetReset` 系统维护。

## 客户端设置（访问方）

如果其他 Windows 电脑无法访问，请在**访问方电脑**上执行：

1. **启用不安全的来宾登录**
   - Win+R → `gpedit.msc` → 计算机配置 → 管理模板 → 网络 → Lanman 工作站 → 启用"不安全的来宾登录"
   - 或注册表：`HKLM\SOFTWARE\Policies\Microsoft\Windows\LanmanWorkstation` 新建 DWORD `AllowInsecureGuestAuth` = 1

2. **安装 SMB 1.0/CIFS 客户端**
   - 控制面板 → 程序 → 启用或关闭 Windows 功能 → 勾选"SMB 1.0/CIFS 文件共享支持"

3. **优先用 IP 访问**
   - 不要用电脑名，直接输入 `\\对方IP`（如 `\\192.168.1.100`）

## 常见错误

| 错误代码 | 含义 | 原因 | 解决 |
|---|---|---|---|
| 0x80070035 | 找不到网络路径 | 电脑名解析失败 / 防火墙拦截 | 用 IP 访问，检查防火墙 |
| 0x80070035 | 找不到网络路径 | 客户端未启用 SMB1 客户端 | 安装 SMB 1.0/CIFS 客户端 |
| 0x80004005 | 未指定的错误 | 客户端禁止了不安全的来宾登录 | 启用"不安全的来宾登录" |
| 0x80070005 | 拒绝访问 | 权限不足 / Guest 账户被禁用 | 检查 Guest 账户和共享权限 |
| 0x80070013 | 网络名不再可用 | SMB1 未启用 / Server 服务停止 | 重新运行本工具配置 |
| 0x80070043 | 网络名找不到 | NetBIOS 未启用 | 用 IP 地址访问 |
| 0x8007052E | 登录失败 | 用户名或密码错误 | 输入正确的 Windows 账号密码 |
| 0x80070079 | 语义转换错误 | 大文件传输中网络中断 | 重新传输 |
